Die Datenverarbeitung auf dieser Website erfolgt durch den Websitebetreiber (siehe „Verantwortliche Stelle“). Daten werden zum einen erhoben, wenn Sie uns diese mitteilen, etwa wenn Sie uns eine E-Mail schreiben. Andere Daten werden automatisch beim Besuch der Website erfasst, vor allem technische Daten (z.
